# 잡지·지면 만들기: 사진, PDF, 슬라이드 → 무드가 살아 있는 지면

사용자는 슬래시 명령 없이 그냥 말한다. 예: "사진 넣고 이렇게 잡지 만들어줘", "이 PDF 판매 가능하게".
이런 요청이면 이 절차를 **그대로** 따른다. 승인된 결과의 방식이다.
- **MATCH 부드러운 댄디**: `edas/mood/contemporary.py:nocturne_dandy`
- **STOP 라포**: `edas/mood/rapport.py:rapport_spread`

막히지 않는 한 되묻지 않는다. 해석이 갈리면 한 줄로 밝히고 진행한다.
예: "라포틱" → 라포(rapport)로 해석.

## 경로 고르기

| 들어온 것 | 경로 |
|---|---|
| 이미지 1장 + 무드 | **A**: 1~8절 |
| 이미지(들), 무드 없음 / "알아서" | **B**: 2절 뒤에 **B절**(무드 스스로 고르기), 그다음 3~8절 |
| PDF·슬라이드·여러 페이지 | **C**: **C절**로 페이지를 꺼내고, 페이지마다 B절로 무드를 계획한 뒤, 3~8절을 페이지별로 반복 |
| "판매 가능하게 / 인쇄용 / 실제 출간" | C 경로에 **D절**(생산)을 더한다 |

## 0. 지켜야 할 것

- **원본 파일**
  - 원본은 수정하지 않는다. 복사본으로 작업한다.
- **사진**
  - 생성하거나 지우거나 덧그리지(inpaint) 않는다.
  - 허용하는 처리: 자르기, 확대, 반전, 반복, 기하 변형(나선 등), 톤 처리(매트, 헐레이션, 블러).
  - 모든 처리를 spec JSON과 답변에 적는다.
- **카피와 수치**
  - 카피는 원문 그대로 둔다.
  - 원문의 중복·오타·시제 섞임은 고치지 말고 보고한다.
  - 지면의 숫자는 실제로 측정한 값만 쓴다(원본 크기, 확대율, 색차 등).
- **출처**
  - 이번 작업에서 실제로 확인한 출처만 인용한다.
  - 못 찾았으면 "근거 없음/관행"이라고 쓴다.
- **판단의 범위**
  - 무드는 디자인 의도이자 가설이다. 측정되었다고 말하지 않는다.
- **승인된 결과 — 절대 퇴화 금지**
  - 승인된 결과는 손대지 않는다. 새 작업은 새 파일과 새 함수로 만든다.
  - `tests/test_mood_approved.py`가 승인작을 원본에서 다시 렌더해 픽셀 해시를 비교한다. 이 테스트가 실패하면 커밋하지 않는다.
  - `edas mood render <name> --image sources/...`가 항상 `identical to the approved file`로 나와야 한다.

## 1. 접수

```sh
edas mood fonts            # pretendard / notoserifkr 둘 다 ok 여야 한다 (edas/fontfiles에 번들됨)
edas mood new <slug> --image <원본경로> --mood "<무드 또는 auto>"
```

- 이미지가 대화에 붙어 왔으면 업로드 경로(`~/.claude/uploads/...`)를 `--image`에 넘긴다.
- 그러면 `output/<slug>/original.*`과 `brief.json`이 생긴다.

## 2. 원본 읽기

- **좌표 읽기**: `edas mood grid output/<slug>/original.* --region X0 Y0 X1 Y1 --zoom 3 -o /tmp/g.png`
  - 이 이미지를 열어 다음 좌표를 원본 px로 읽는다:
    - 사진 영역(crop)
    - 주인공·사람 박스(person)
    - 옷·소재 영역(outfit)
- **원본에 박힌 요소**: 번호 라벨, 점선 박스, 그래픽 등을 확인한다.
  - 라벨은 잘라내도 된다.
  - 점선 박스처럼 사진에 박힌 것은 그대로 둔다.
- **카피 전사**: 모든 카피를 확대 crop으로 확인해 글자 그대로 옮긴다.
- **데이터 파일**: 위 내용을 `edas/mood/spreads/<slug>.py`에 적는다.
  - 형식은 `match.py`(Photo 목록) 또는 `stop.py`(CELLS)를 따른다.
  - 측정 방법은 docstring에 쓴다.

## B. 무드를 스스로 고르기 (무드가 주어지지 않았거나 여러 페이지일 때)

1. **사진 영역별로 읽는다**: `edas mood read <crop 폴더 또는 이미지>`
   - 지면 전체를 읽으면 배경색이 측정을 지배한다. 사진을 crop해서 읽는다.
   - 여기서 나오는 단서(cues)는 측정값과 관행 임계값이다. 감정 점수가 아니다.
2. **내용을 본다**: 카피 주제를 한 줄로 요약하고, 주인공(사람, 장소, 사물), 시간대, 행동을 적는다.
3. **`docs/mood_library.md`와 맞춰 본다**: 무드를 고르고 근거를 한 줄로 쓴다.
   - **맞는 것이 없으면 새 무드를 만든다.** 라이브러리는 출발점일 뿐 한계가 아니다. 댄디와 라포도 처음엔 라이브러리에 없었다.
     1. 무드 이름을 정하고 해석을 한 줄로 밝힌다. 예: 라포틱 → rapport.
     2. 3절대로 조사한다. 그 무드의 구성 요소를 나눈 출처 하나와 맞는 현대 예술 기법 하나를 찾는다.
     3. 구성 요소마다 지면 장치 하나를 정한다(4절 무드 레이어 표 형식). 팔레트, 서체, 처리, 배치.
     4. **무드를 바꾸면 지면 전체를 다시 짠다**: 레이아웃, 서체, 처리, 색 모두. 고정되는 것은 승인작 3장의 픽셀 동일뿐이다(사용자: "지난 세션에서는 무드 바꾸면 다 바꿨는데"). 시리즈 공통 요소(원본 크기·확대율 표기 등)는 무드에 맞으면 넣는다.
     5. 새 함수로 만든다(`edas/mood/<무드>.py` 또는 구조별 `edas/mood/kinds/<kind>.py`). 기존 승인 함수는 고치지 않는다.
     6. **무드 작가 ↔ 편집 구조로 돌린다** (`docs/mood_relay.md`). 작가는 무드마다 `structure` 블록(배치 자체)까지 쓰고, 구조별 렌더러가 그 배치를 그리고, 심판(`edas/mood/judge.py`)이 판정한다.
        - 먼저 후보 무드 여러 개를 기계적으로 뽑아 한 번에 렌더한다(`python3 scripts/mood_editor.py` → 각 폴더 `preview.jpg`).
        - 그중 하나를 골라 조사(출처 확인)하고 다듬는다.
        - 반려된 초기 방식(`photo_led` 색 칩·ΔE, `variants` 원본 팔레트·작은 프린트 나열)으로 돌아가지 않는다.
        - 이전 세션의 전 과정을 다시 보려면: `python3 scripts/replay_match_flow.py [new]`.
4. **여러 페이지일 때**:
   - 시리즈 DNA는 공통으로 넣는다.
   - 무드 레이어만 페이지마다 바꾼다.
   - 강약 리듬을 짠다. 표지는 가장 강하게, 텍스트가 많은 페이지는 읽히게.
5. **계획표를 먼저 보여 주고 바로 만든다.** 형식: 페이지 | 단서 | 카피 주제 | 무드 | 이유.

## C. PDF·슬라이드·여러 페이지

```sh
edas mood pdf-extract FILE.pdf -o output/<slug>/pages   # 페이지 미리보기 + 원본 해상도 이미지 + ppi
edas mood read FILE.pdf                                 # 페이지별 단서와 텍스트
edas analyze FILE.pdf -o output/<slug>/analysis         # (필요하면) 레이아웃·타이포 측정
```

- **원본 이미지**: PDF에서 꺼낸 원본 이미지를 쓴다. 스크린샷보다 훨씬 선명하다.
- **카피**: 텍스트는 PDF 텍스트 레이어에서 가져온다. 텍스트 레이어가 없으면 확대해서 전사한다.
- **보호 페이지**: 기존 포트폴리오 PDF라면 `docs/postmortems/vmd-redesign-failure.md`를 따른다.
  - 원본 PDF는 수정하지 않는다.
  - 보호 페이지는 바꾸지 않는다.
  - 승인 전에는 "최종"이라고 부르지 않는다.

## D. 판매 가능한 생산본 (인쇄용)

- **판형(trim)**
  - PDF가 있으면 PDF 페이지 크기를 쓴다.
  - 없고 사용자도 정하지 않았으면 판형만 한 번 묻는다. 출판물마다 다르다.
- **도련(bleed)**: 기본 3mm. 관행이다.
- **렌더 크기**: 페이지를 (판형 + 도련 2개) × 300ppi 크기로 그린다. 300ppi도 관행이다.
  - 새 함수는 캔버스 W, H를 인자로 받는다. 2000px로 만든 좌표는 W/2000 비율로 늘린다.
- **조립**: `edas mood print-pdf page_*.png --trim WxH --bleed 3 -o output/<slug>/print.pdf`
  - TrimBox와 BleedBox가 들어간다.
- **점검 결과**를 답변에 표로 보고한다:
  - 이미지별 유효 ppi(300 미만은 표시)
  - 텍스트가 래스터라는 점(벡터 텍스트가 필요하면 조판 프로그램에서 다시 짜야 함)
  - RGB 출력이라 CMYK 변환은 인쇄소 몫이라는 점
  - 서체 라이선스: Pretendard, Noto Serif KR는 OFL이라 상업 사용 가능
  - 사진 권리는 사용자 확인 사항
- **"판매 가능"을 장담하지 않는다.** 위 점검 항목이 충족됐는지만 보고한다.

## 3. 무드 해석과 조사 (검색 2~4회, 한 번에 병렬로)

- **(a) 무드의 근거**: 그 무드 개념을 구성 요소로 나눈 1차 문헌이나 학술 출처를 찾는다.
  - 예: 라포 = 주의, 긍정, 조율(Tickle-Degnen & Rosenthal 1990), 대인 거리(Hall 1966).
- **(b) 현대 예술 기법**: 이 무드와 내용에 맞는 기법의 원작과 출처를 찾는다.
- **사람 사이 연구를 지면에 옮길 때**: "디자인 비유, 검증 안 됨"이라고 밝힌다.

## 4. 설계 레시피 (승인된 결과를 만든 것)

### 강도

1라운드 수준을 맞춘다. 과감하고, 구조적 아이디어가 하나 강하게 있고, **읽힌다**.

| 반려된 방향 | 이유 |
|---|---|
| 정돈된 그리드형 | 무드·감각과 거리가 멀다 |
| 기법을 겹겹이 쌓은 것 | "볼 수 없을 정도로 과감" |
| 기법 하나만 남긴 차분한 정제본 | "아니야" |

### 구조

카피가 말하는 아이디어 하나를 지면 구조로 만든다.
- **NOCTURNE**: 왼쪽 면 전체를 주인공 사진으로 채우고(풀블리드), 접히는 선을 따라 세로 제목, 작은 프린트 세 장.
- **STOP**: "멈춘 사람"만 선명하게, 여섯 명의 중심을 하나의 눈높이 선에 정렬, 사진들이 어깨를 맞대듯 겹침.

### 시리즈 DNA (매번 넣는다)

- **Richter식 줄무늬**: 사진의 한 열을 나누고, 뒤집어 붙이고, 반복해(divided/mirrored/repeated) 제목 안에 채운다(`contemporary.richter_strip` + `defamiliar.text_mask`).
  - 줄무늬 원천은 무드에 맞는 사진 부분에서 고른다. 니트(댄디), 가게 불빛(라포).
- **가난한 이미지 정직성(Steyerl)**: 원본 크기와 확대율을 지면에 적는다.

### 기법 팔레트 (2~3개만 고른다)

| 함수 | 효과 |
|---|---|
| `defamiliar.slit_scan` | 시간, 잔상 |
| `contemporary.halation` | 따뜻한 빛 번짐 |
| `contemporary.matte` / `rapport.warm_matte` | 바랜 인화 |
| `rapport.motion_outside` | 주체만 선명하게 |
| `final.progressive_blur` | 점점 흐려지는 블러 |
| `contemporary.ruff_jpeg` / `soft_jpeg` | 최대 압축 그림자(Ruff) |
| `defamiliar2.pixel_stretch` | 가장자리 늘이기 |
| `defamiliar.misregister` | 인쇄 어긋남 |

### 무드 레이어

조사한 구성 요소를 아래 네 가지에 하나씩 대응시킨다:
- **팔레트**: 가능하면 원본에서 색상(hue)을 샘플한다.
- **서체**
- **처리 강도**
- **배치**

| 무드 | 종이 / 잉크 | 서체 | 처리 |
|---|---|---|---|
| 부드러운 댄디 | 아이보리 (233,227,216) / 웜 차콜 (58,54,50), 토프·카멜 | Noto Serif KR Light/SemiBold, Caladea Italic 캡션 | 매트 24/240, 헐레이션, 슬릿스캔 amp 40, 토프 JPEG 그림자, 얇은 테두리 |
| 라포 | 크림 (239,231,217) / 웜 브라운 (70,52,42), 원본 라벨 색상의 테라코타 | Noto Serif KR, Caladea Italic | 주체 밖 모션블러, 따뜻한 헐레이션·매트, 눈높이 정렬, 겹침 그림자 |

### 타이포

- 한글은 Pretendard(`final.kr`) 또는 Noto Serif KR(`contemporary.serif_kr`)만 쓴다.
- 서체 파일 경로는 `edas.fontpaths.find("파일명")`으로만 얻는다. `/usr/share/fonts` 같은 시스템 경로를 쓰지 않는다(Mac에서 깨진다).
- JetBrains Mono에는 한글이 없다. 섞어 써야 하면 `final.mixed`를 쓴다.
- 지면에 분석용 숫자를 늘어놓지 않는다. 공정 설명은 한두 줄로 작게 쓴다.

### 캔버스

- 시안은 원본 비율을 따르고 폭 2000px로 한다. 여백 40~56px.
- 생산본은 D절을 따른다.

## 5. 만들기

- **코드 위치**
  - `edas/mood/<slug>.py`에 `<slug>_spread(...) -> (page, spec)`를 만든다.
  - 기존 함수를 고치지 말고 import해서 재사용한다.
- **spec 내용**
  - 무드 의도, 처리 목록과 수치, 출처, 카피 관련 보고.
- **등록**
  - `edas/mood/spreads/__init__.py`의 `WORKS`에 등록한다.
  - 원본은 `sources/`에 둔다.
- **렌더 위치**
  - `output/<slug>/`

## 6. 눈으로 확인하기 (2~4회 반복)

**품질 기준선**: 전달하기 전에 새 시안을 `docs/approved/*.jpg`(승인작 3장)와 나란히 Read로 본다.
- 과감함, 완성도, 무드의 분명함이 승인작보다 낮으면 전달하지 않고 고친다.

축소본을 Read로 직접 보고, 세부는 확대 crop으로 본다. 확인할 것:
- 글자 충돌, 잘림, 지면 밖으로 나간 라벨
- 복잡한 사진 위에서 안 읽히는 글자(필요하면 scrim)
- 두부 글자(□), 고정폭 글꼴의 한글
- 겹침에 가려진 주인공·사람
- 줄무늬 제목이 회색 단색으로 보이지 않는지(원천 열을 바꾼다)

## 7. 전달

- **시안 수**: 페이지당 시안 한 장. 변형은 요청할 때만 만든다.
- **여러 페이지일 때**: 페이지별 PNG, 합본 PDF, 전체 컨택트 시트 한 장을 보낸다.
- **파일**: `SendUserFile`로 PNG와 PDF를 보낸다.
- **답변(한국어)**:
  1. 해석 한 줄
  2. 표: 무드 구성 요소 → 지면 장치
  3. 서체
  4. **알려 드릴 점**: 해석, 원문 문제, 사진 처리 목록, 해상도 한계, 무드는 가설이라는 점
  5. 출처 링크
- **기록**:
  - `docs/mood_techniques.md`에 한 단락 추가한다.
  - 테스트를 실행한다(`python3 -m unittest discover -s tests -t .`).
  - 승인 해시가 그대로인지 확인한다(`edas mood render ...`).
  - 동작 방식이 바뀌었으면 `intent.md`도 고친다.
  - 현재 브랜치에 커밋하고 push한다.
