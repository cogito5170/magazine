# 정전 기반 미감 기준 (초안 v1, 2026-10-25)

근거: 정전 레퍼런스 보드 37건, 이미지 67장 (`docs/canon/board.json`, `docs/canon/img/`). 수집: GPT(Codex, 웹 검색), 출처 대조: Claude.
용도: 디자인 원칙 비평가(VLM)와 생성 단계가 시안을 보기 전에 먼저 읽는 판정 기준. 번호는 보드 번호.

## 0. 최상위 축 (윤경)

- 익숙한 낯섦: 관습적 문법을 유지하고 정확히 한 요소에서 낯설게하기(ostranenie)를 일으킨다.
- 과감한 안정: 과감함은 한 축에 몰아주고, 나머지 변수는 절제로 묶는다.

## 1. 주도 장치는 하나

시안마다 주도 장치(dominant device)를 하나만 명시한다. 아래 목록에 없는 장치를 쓰려면 정전 근거를 함께 든다.

| 장치 | 정전 근거 |
| --- | --- |
| 마스트헤드 침범 (전경과 배경 레이어 역전) | 01, 19, 30, 09 |
| 디스플레이 타입의 음절 분절 스택 | 14, 28 |
| 타입의 이미지화 (자폭·기울기·굴곡 중 한 변수만 극단화) | 11–13, 20, 26 |
| 단일 오브제 + 활성 네거티브 스페이스 | 05, 25, 17 |
| 펼침면 형태 운율 (좌우 윤곽 호응, 거터 횡단) | 18, 16, 14 |
| 본문 블록을 질감으로 | 10, 36, 27 |
| 비연출 스냅 사진 + 고전 세리프의 대비 | 37, 35, 33 |

판정: 주도 장치가 둘 이상 동등한 강도로 경쟁하면 감점한다. 승인 레시피의 사진 처리(halation, matte, JPEG 그림자 등)는 승인 강도 그대로 마감으로 쓰며, 주도 장치와 경쟁할 만큼 눈에 띄면 감점 대상이다. 레시피의 값은 바꾸지 않는다.

## 2. 절제되어야 하는 변수

- 팔레트: 사진 + 색면 1–2개 (032c 빨강, Buffalo 빨강, Kindling 녹색). 색면은 매체 정체성으로 일관되게 쓴다.
- 본문 조판: 정형 단 구성, 일정한 행간, 판면 안에서 정렬. 낯설게하기는 디스플레이 층에서만 일어난다.
- 서체 수: 디스플레이 1 + 본문 1 (Fantastic Man #30은 단일 서체 체계).
- 여백: 남은 공간이 아니라 긴장을 만드는 면이다. 여백을 장식으로 메우지 않는다.

## 3. 타이포그래피 위계

- 디스플레이와 본문의 스케일 대비가 크다. 중간 크기의 제목이 판면을 지배하는 상태를 피한다.
- 디도네 계열 세리프는 고대비 획 자체가 이미지 역할을 할 만큼 크게 쓴다 (14, 19, 28, 37).
- 콘덴스드 그로테스크는 판면 높이나 폭 전체를 쓰는 규모로 쓴다 (20, 26).

## 4. 사진

- 크롭은 결단적이다: 정면 응시 클로즈업 또는 단일 오브제. 애매한 중간 거리 크롭을 피한다.
- 사진 처리(필터·질감)가 주도 장치가 아니라면 사진은 손대지 않는다.

## 5. 물성

- 정전의 상당수는 접지·다이컷·노출 제본·판형으로 낯섦을 만든다 (12, 13, 15, 17, 32). 화면이나 PDF 시안에서는 대체 장치를 찾거나 물성 제안을 별도로 적는다.

## 6. 비평가 출력 형식

출력은 JSON이다 (`edas/mood/canon.py`의 `validate_critique`가 검사). 축마다 문장 등급(나쁨 / 미흡 / 보통 / 좋음 / 훌륭함)과 가장 가까운 정전 번호를 적는다.
축: 주도 장치의 명료성, 절제 변수의 통제, 타이포 위계, 네거티브 스페이스, 사진 크롭, 익숙함, 낯섦, 과감함, 안정.
