# Bundled fonts

Exact copies of the files the approved spreads were rendered with, so rendering needs no system font folder
(macOS, Linux, Windows). Resolved by `edas/fontpaths.py`, which always prefers these copies.

| Files | Family | Licence (full text in `LICENSES/`) |
|---|---|---|
| `InterDisplay-*.otf` | Inter Display | SIL OFL 1.1 |
| `Caladea-*.ttf` | Caladea | SIL OFL 1.1 / Apache 2.0 (`fonts-crosextra-caladea.txt`) |
| `JetBrainsMono-Light.ttf` | JetBrains Mono | SIL OFL 1.1 |
| `Liberation*.ttf` | Liberation | SIL OFL 1.1 |
| `wqy-zenhei.ttc` | WenQuanYi Zen Hei | GPL-2 with font embedding exception |
| `pretendard/` | Pretendard 1.3.9 | SIL OFL 1.1 (`pretendard/LICENSE.txt`) |
| `notoserifkr/` | Noto Serif KR 2.003 | SIL OFL 1.1 (`notoserifkr/LICENSE`) |
